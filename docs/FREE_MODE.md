# 免費模式：原生分享貼文到 My X

本 App 不使用付費 X Developer API、外部下載服務或 WebView。

## 使用方法

1. 在 X Android App 找到公開貼文，點選「分享」。
2. 透過 Android 系統分享選單選擇 My X。
3. My X 會進入「探索」頁，自動填入貼文網址。
4. 點「解析媒體」，查看圖片／影片並選擇下載。

同樣可以直接在探索頁點「貼上」，貼入複製好的 X 或 Twitter 貼文連結。兩個入口均不會把憑證傳給第三方下載網站。

## 登入與免費限制

目前的 `XApiClient.kt` 仍使用非官方、需要有效 X 工作階段 Cookie 的 API。此模式**不需要 X Developer API 收費**，但新用戶可能必須手動匯入既有的 `auth_token` 與 `ct0`。登入 X 的系統瀏覽器不會向 App 暴露 Cookie。App 不會索取帳號密碼。

- 沒有工作階段時，App 會要求先設定憑證，無法保證無登入解析。
- 非官方資料接口可能變更、限流、要求驗證或停止服務；不是官方保證長期免費的 API。
- 私人貼文、刪除貼文、無權限檢視的內容不可藉此取得。
- 只下載你有權存取及使用的媒體，並尊重著作權與平台條款。
